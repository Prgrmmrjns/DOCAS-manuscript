MIMIC-IV tabular dataset (processed for iSHAP).

Source file: mimic-iv.csv
Processed file: mimic-iv_processed.csv

Processing steps:
- Selected only raw measurements needed by the SOFA calculator notebook logic.
- Computed component scores by hand: respiration, cardiovascular, liver, coagulation, renal, coma.
- Computed total SOFA target as the sum of six component scores.
- Rows with non-physical / missing component inputs keep NaN component score; SOFA is NaN if any component is NaN.
- Ensured unique column names by appending suffixes when needed.

Outcome column: sofa (regression).
Number of features (excluding outcome): 17

Feature list (processed names):
pao2_fio2, ventilation, platelets, bilirubin, map, gcs, creatinine, urine_output, dobutamine, epinephrine, norepinephrine, respiration_score, cardiovascular_score, liver_score, coagulation_score, renal_score, coma_score
