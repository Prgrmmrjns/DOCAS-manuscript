\begin{abstract}
We outline \textbf{iSHAP} (interventional SHAP), a data-centric proposal: iteratively synthesize training rows so a fitted predictor better matches lightweight \emph{structural} rules (e.g.\ monotonicity of an intervention on the outcome) while tracking ordinary hold-out task performance.
Feasibility is scored from \emph{interventional} summaries of the model (\emph{do}-style sweeps on held-out covariate rows), not from post-hoc explanation plots alone.
Optimization uses a scalar or Pareto-style trade-off between performance and feasibility; augmentation stops when the combined score no longer improves.
\end{abstract}

\section{Motivation}
Predictive models often achieve strong metrics yet violate simple domain expectations (e.g.\ higher insulin should not predict higher future glucose under intervention; higher PM2.5 should not predict higher student grades).
Post-hoc explanations do not fix the training distribution.
iSHAP proposes to \emph{augment} training data with synthetic points chosen to improve both validation performance and interventional alignment with user-specified rules.

\section{Methodology}
The pipeline (Figure~\ref{fig:flow}) is a loop with one clear quality criterion: \emph{does adding this synthetic batch make the model both more accurate and more rule-consistent?}

\begin{enumerate}
    \item \textbf{Specify rules.} The user writes a small set of directed expectations
    $u \rightarrow v$ with a qualitative behavior (e.g.\ ``higher insulin $\Rightarrow$ lower future glucose'', monotone decrease).
    No numerical effect sizes are required.
    \item \textbf{Train a baseline.} Fit a predictive model (e.g.\ LightGBM) on the real training split.
    Record hold-out performance with the task-appropriate metric (RMSE for regression, accuracy for classification).
    \item \textbf{Score baseline feasibility.} For each rule $u\rightarrow v$, sweep $u$ over a grid on a fixed set of held-out covariate rows and compute the interventional mean
    $\bar f(g) = \frac{1}{n}\sum_{i} f(X^{(i)}_{\neg u},\, u{=}g)$.
    Compare $\bar f$ to the expected qualitative shape; aggregate per-rule alignments into a single feasibility score in $[0,1]$.
    \item \textbf{Propose a synthetic batch.} Use a Bayesian optimizer (e.g.\ Optuna TPE) to sample a batch of candidate rows $(X_s, y_s)$ within feature bounds.
    \item \textbf{Retrain and re-evaluate.} Fit a fresh model on real data plus the candidate batch; recompute validation loss and feasibility.
    \item \textbf{Accept or stop.} Combine the two numbers via a weight $\lambda$ (or Pareto comparison): \\
    $\text{score} = (1-\lambda)\,(1-\text{normalized loss}) + \lambda\,\text{feasibility}$. \\
    Append the batch if the combined score strictly improves; otherwise stop.
    \item \textbf{Finalize and audit.} Train a final model on real data plus all accepted synthetic rows.
    Predict on test data, re-render the interventional curves, and store curves and JSON summaries for transparent inspection.
    \item \textbf{Optional feedback.} Rules can be refined from new domain input or from a separate causal-discovery step, restarting the loop with updated expectations.
\end{enumerate}
